# Native Matrix Studio examples

The author requested actual Matrix Studio code for the interactive Aura and the relevant starter activities. The original three DOCX proposals, original teacher PDF, existing reading text and course expansions remain unchanged. Later references continue to inform visual choices and placement only.

The moving Aura uses the actual Studio `AuraView`, `core.js` and `spatial.js` with their existing module dependencies and pinned local Three.js library. The native files are unchanged apart from repository line endings. Source hashes and licences are in `assets/matrix-studio/upstream-manifest.json`. The lesson host supplies controls and a prepared project; it does not implement another geometry renderer. Native drag rotation, wheel/pinch zoom, raycast facet/stack picking, inside/outside cameras, grouped facets and source presets remain available. Keyboard turns, zoom, numbered-map navigation and facet-number selection provide alternatives to gestures.

The starter iframe reuses the actual QuickStart favourites, guided-entry and allocation functions, the native family UI, and Studio writers for favourites, skills, goals, milestones, timing, travel and avatar preferences. Its nine entry stages are selected beside matching existing passages. Source fragments, changes and hashes are listed in `assets/matrix-starter/upstream-manifest.json`. Adaptations bind source functions to a sample project, restrict unrelated launch routes, and hand the same project and selected address to the real renderer. The native family page is used directly; the QuickStart family-to-dating alias is not used.

Each example owns an in-memory fictional copy. The Studio's browser-storage project is not loaded or changed. Prepared dates are fictional review points, timing remains manual/disabled, and fixed vectors are not live embeddings. There is no account, upload, model call or publishing action. Reset restores the prepared project; download produces a genuine native Studio project. Native table allocation retains real source-table/row references, appends stack layers and avoids reallocating the same rows.

The seven-context bundle in `assets/matrix-studio-samples.json` contains complete native projects, not a substitute schema. Each has 98 records, 14 stacks, 14 bound vector fixtures, ten tables and four native sequences, plus the value/experience/favourite defaults and source-compatible menu data. `assets/matrix-studio/samples.js` supplies the same data to the modules.

Existing exact mathematical SVGs remain static and print fallbacks. Starter figures have source-derived sample summaries without JavaScript. A child-ready handshake hides the summary only after the native activity mounts; origin/source-checked height messages keep the embedded activity in the normal reading flow.

Validation covers source/adaptation hashes, local module imports, all contextual mounts and the actual native writers, schema, record recall and stack allocation in all seven contexts. The native test traps any accidental real browser-storage or fetch access. Browser checks include direct drag, surface picking, inside views, grouped facets, stack selection, a changed favourite through native allocation into its exact rendered stack layer, return navigation and 390/320px layouts. The website's unchanged-content checks remain separate.
