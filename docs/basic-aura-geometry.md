# Basic Aura geometry only

30 October 2026. The author withdrew the added starter activities, sample records, data assignments, cardboard-world diagrams and other demonstrations from the four reading websites. The retained interaction is only seven native horn tori, facet selection and a persistent Inside/Outside toggle.

The renderer, geometry and schema dependencies are unchanged Aura Matrix Studio source, pinned in assets/matrix-studio/upstream-manifest.json. The host starts with blankProject, with no records, tables, links, stacks, vectors or imported project. It never reads Matrix Studio storage. Each torus/side has its own selected facet, initially 1; switching surfaces restores that surface's selection instead of transferring another surface's selection. The source renderer remains responsible for rotation, zoom, picking and inside perspective.

The proposal readings, sixty-day course and scene illustrations are unchanged. The original three DOCX files and teacher PDF continue to govern written content. Development of Q&A, recall, automatic organisation, granular record editing and wider system behaviour belongs in Matrix Studio; these websites must not invent demonstrations of those behaviours.
